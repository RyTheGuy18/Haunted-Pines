# Haunted Pines

First-person co-op horror. Find 5 radio parts in the woods and call for help. It only moves when no light is on it.

Play / install: https://rytheguy18.github.io/Haunted-Pines/

Online: tap HOST GAME for a 4-letter code, friends tap JOIN and enter it (2–4 players, any device).

On iPhone: open in Safari, Share, Add to Home Screen. Headphones on.
