# Level 0 — The Backrooms (repo: RyTheGuy18/Haunted-Pines)

Notes for future Claude sessions. Read this before changing anything.

First-person co-op Backrooms horror game for 1–4 players, played in the browser (desktop + phones, installable as a PWA). Survivors escape Level 0, then Level 1, then Level 37 (the Poolrooms), then Level 188 (the Hotel), then Level 852 (the Mall), then Level 2 (Pipe Dreams), while one player (or the computer) is **the Occupant** hunting them. The repo is still named Haunted-Pines, from an older scrapped concept (a foggy-woods campground); the game itself is "Level 0".

- Live: https://rytheguy18.github.io/Haunted-Pines/ (GitHub Pages, `main` branch, repo root)
- Owner: Ryan (GitHub `rytheguy18` / `RyTheGuy18`). Plays it with friends and younger brothers, mostly on phones.
- Current version: **v0.35.2** (shown bottom-right of the menu, `#ver`)

## Gameplay as it stands

**Level 0 (the office)** — **19×19** grid of 4 m cells (v0.28, was 16; `GRID_N(0)`, `CS=4`), wall height 2.8 m. 9 batteries. Three zones: office (yellow wallpaper/carpet), parking corner (concrete), "the pitfalls" (pits with ~1.2 m walkways; falling = death). Maze from DFS + random openings (`rng()<0.43` = how open), plus big halls, tight corridor blocks and a red room. The **clean office** was removed in v0.28 (Ryan): `L.clean = null`, its build/clock code is dead. Office + pitfalls floors use `rugTex` (pitfall walkways are one merged mesh with world-space UVs); the parking corner keeps concrete.
- Goal: find **3 fuses** → put them in the **breaker** → exit door opens → reach it.
- Walls **shift** where nobody is looking (every 20–35 s, never visible ones). **Level 0 only** — Ryan wants no moving walls on Level 1 or 37 (hostTick only shifts on `G.lv===0`; the Occupant's SHIFT ability says "The walls here don't move" on later levels).
- Items: batteries (flashlight), lockers (hide; hold breath bar; **the Occupant can't open lockers**). **Almond water, sanity and the rolling office chair were removed in v0.20, and throwable cans in v0.26.4 (Ryan's call — don't add back).** `L.cn`/`G.cn`/`throwCan` remain as empty/dead code. `G.aw`/`level.aw` still exist as empty arrays.
- Phones ring and give hints (sometimes "found you"). **v0.30:** ring = `phone-ring.mp3` (gain 0.32 since v0.31, every 4 s; **v0.35.2:** fades by distance from you, full inside `RING_NEAR` 10 m, silent past `RING_FAR` 22 m — Ryan: heard from too far away; Level 37's PA chime unchanged), answering (walk within 1.5 m) plays `phone-pick-up` then static; the voice says the direction **relative to where you're facing** (`relDir`: straight ahead / ahead off to your left / to your right / behind you…), and a faint arrow + "what · N m" (`#guide`, `setGuide`/`updateGuide`, 14 s) points the way and turns as you turn; on the hotel, if it's on another floor the arrow points to the nearest elevator landing ("elevator → floor N"). Wall phones (Level 0/1 + hotel) use `models/telephone.glb` (`phoneModel`/`fillPhone`, box phone until it loads). Lying EXIT signs, scrawls, doors to nowhere, wet footprints into walls, an off-the-hook phone (dial tone).
- **The exit door** (both grid levels) is only put on a boundary cell that's not in a tight maze block or the pitfalls, has no tight/pit neighbours and no pillar at its corners (`exitOk`), preferring far cells. **v0.26.5:** the exit cell's inner edges are forced open and marked `L.fixed` (walls never shift there), so the door can't be walled in. Reachability was checked with a 0.2 m flood fill using the real `collide` + `inPit` (45 seeds × up to 25 shift rounds on Level 0, Level 1 too): always reachable.
- When **every living survivor** has escaped, after 3.5 s the whole room goes to the next level (0 → 1 → 37 → 188 → 852 → 2). **Everyone caught on Level 0 comes back** for Level 1 (`G.dead` is cleared).

**Level 1 (parking garage)** — `LK = 1`, `zoneOf()` returns 1 everywhere. **v0.25: the grid size is per level** (`let N/W/VN/E`, `setGrid(GRID_N(kind))` at the top of `buildLevel`; Level 1 = **28×28 cells, 112 m**, everything else 16). Concrete, pillar grid, **no parked cars** (removed in v0.26.3 at Ryan's request — don't add back), 11 batteries, 8 lockers. All lights off, darker for survivors (ambient 0.09) and **quiet**: no fluorescent hum, room tone 0.04. **5 generators** (spread out, min distance up to 40 m): stand next to one and hold START GENERATOR for **9 s** (`GEN_T`). Starting one is LOUD: noise level 3 while cranking, `useReq({k:'crank'})` sends the computer Occupant straight there (hunt, `GEN_T+20` s; again when it finishes), everyone hears the start-up recording looping at that generator (`crankWatch` → `genCrankSound(i,on)`, snd `crank`/`crankStop`, auto-stops after `GEN_T+3` s) and a player Occupant gets a message; once it's on, `startGenLoop` plays the running recording; crank/start/running sounds have big ref distances on LK 1. Each one lights only the lamp right above it, and since v0.26 that lamp always gets a point light from the pool however far away you are (unlit garage panels are skipped). All 5 → all lights on + exit opens. **v0.36 (Ryan: still dark at the edges of your view):** once `G.open`, `updateZoneEnv` switches the garage to a light grey fog (0x4a4c4e, density 0.016), hemisphere 0.75 with light colours (`_lit1S/_lit1G`) and turns the fluorescent hum on (0.8) — bright everywhere, you see far. When everyone left alive escapes, the room drops into Level 37 (same 3.5 s advance as 0→1; `advanceLevel()` goes to `G.lv+1`, max 2).

**Level 37 (the Poolrooms)** — rebuilt in v0.21 as a **free-form level with no grid** (Ryan: the first grid version felt too similar). `LK = 2`, `G.lv = 2`. Everything is in the `/* ===== Level 37 ... */` module (search `buildLevel37`):

Corridors (capsules, ~45% are tiled tunnels with arches) = spanning tree over the flooded rooms + loops; **dry rooms only hang off it as dead ends**, so the water is one connected network (checked: 12/12 seeds). Balcony is placed away from corridor entrances; corridors also carve through it/dry rooms if needed.

## Audio

All in the `sfx` object (Web Audio, HRTF panners). Procedural sounds for most things; recorded samples loaded in `sfx.loadSamples()`:
- Occupant footsteps are **looped samples** that follow it in 3D (`updateOccLoops`): spider walking for the Crawler, heavy steps for everyone else; faster when sprinting. **v0.27.1 (Ryan: could hear the Crawler across the whole floor):** the Crawler loop is ×0.85 and fades to nothing between 9 and 20 m, its panner is ref 3 / rolloff 1.5 (others 5 / 1.0), and it plays slower (0.82, 1.0 when sprinting). Disguised + far = normal survivor steps instead.
- Kill sounds: Crawler = random spider attack 1/2/4, all others = spider attack 2. Others nearby hear it positionally (`G.kl` = list of players killed by the Occupant). **When the computer catches you, the monster roar plays on top of the bite.**
- Computer chasing (`G.ach`, set while it can see you): `monster-groans` loop follows it in 3D + `monster-growl` every 3.5–7.5 s. Player Occupants don't get these.
- **Wading** (v0.24): on Level 37 shallow water (`wadingAt`) survivors' footsteps are the looping recordings (`sfx.wade(owner, mode, pos)`: mode 1 walk, 2 run, 3 crouch = walk loop quieter/slower; per-person nodes on `o.wd`, positional for remotes, `stopWade` on leave) instead of single steps. **Out of breath**: once a survivor is `winded`, `sfx.puff()` loops `breathing.mp3`, fading with stamina until it's full again (`me.puffing`, gain ≤0.35 since v0.25); silenced outside play.
- **Survivor footsteps** (v0.26.6): `sfx.step` plays a random recorded step via `stepSample` (random slot, never the same twice, pitch ±7%) chosen by `stepSurf(x,z)`: Level 0 = carpet (`stepC`, everywhere on Level 0), Level 1 = concrete (`stepK`), Level 37 = tile (`stepT`) only off the water, Level 188 = wood (`stepW`, v0.27.1) (WATER/DEEP → wading loops / old procedural step). Volume = the old step volumes × `STEP_GAIN` — **v0.29: {C 0.28, K 0.45, T 0.3, W 0.28}** (Ryan: still too loud) — and only the first `STEP_LEN` 0.24 s of each 0.42 s slot plays, fading out (Ryan heard "a floorboard creak and carpet steps at once": the slots had scuff/creak tails). Tile steps also get an extra send (×1.4) into `sfx.verbG` for the poolrooms echo. Used for your own steps, other survivors' steps and the disguised Occupant's fake steps; the Occupant's own steps are unchanged.
- **v0.29 (Ryan: "weird breathing")**: the random breathy whispers behind you (`whisperT`, dead code now), the procedural low-stamina breaths (`sfx.breath` at stamina < 35) and the whisper at the end of the Occupant's LURE are gone. The LURE is only heavy thumping footsteps running up behind you (brown-noise thud + 52→30 Hz tone, louder than before). The recorded out-of-breath loop and the locker gasp stay.
- Ambience: fluorescent hum (fades when the Occupant is near), room tone, drips, TV static, distant random events (quiet), elevator dings, ceiling creaks + dust, **silence events** (8 s of total quiet), dread drone, heartbeat + phone vibration when it's close.
- **Removed on purpose**: the musical "sting" when you spot the Occupant, and the 8-bit horror noise loop. Don't add them back.

## Multiplayer

PeerJS, host's browser is the hub (star). Room code = 4 letters, peer id `level0-v1-CODE`. Max 4 players.
- Host owns the authoritative state `G` (see `freshState()`), broadcasts it every 0.1 s in play; clients send `presence` (position, flags) every 0.1 s and `use` requests (`useReq` → `applyUse` on the host). One-off sounds go over `snd`.
- `G.lv` = level (0/1/2), `G.gen` generators, `G.fz` fuses, `G.dead/esc/kl`, `G.dg` disguise, `G.ov` Occupant voice option, etc. Level geometry is rebuilt identically on every client from a seed (`baseSeed`, `lvSeed(k)`), walls synced as a hex bitmask.
- Lobby: host picks who's the Occupant (random / computer / a player), skins per player, OCCUPANT VOICE option, COMPUTER difficulty (`G.df`), START AT level (`G.sl` 0/1/2/3 = Level 0/1/37/188; menu button `bLv1` for solo, lobby `bLv` for host; `localStorage['lvl0_start']`). `setupLevel(k)` builds a level into `G` (used by `advanceLevel` and by `hostStartRound` when starting later). End screen: PLAY AGAIN or **BACK TO LOBBY** (keeps the room together).
- `#localnet` in the URL swaps PeerJS for a BroadcastChannel transport (same-browser tabs) — used for automated tests. It has **no voice calls**.

**Proximity voice chat** (`voice` object): PeerJS audio calls, one per pair (lower peer id calls). Opt-in via VOICE CHAT button (menu, lobby, settings). Rules: lobby/end = everyone full volume; in a round survivors fade out by ~12 m (muffled through walls); the Occupant hears survivors; **nobody hears the Occupant** unless the host turned on **OCCUPANT VOICE: MONSTER** — then survivors within ~10 m hear it through `monsterVoice()` (delay-line pitch shifter ~10 semitones down + 38 Hz growl ring-mod + distortion + echo, applied on the receiving side); dead players only talk to dead players. Mic meter under the objective (quiet / HEARD / LOUD). V mutes. Confirmed working by Ryan with real players.
- **v0.28.1 (Ryan: iPhone voice unreliable, others could barely hear him):** the raw mic (`voice.raw`, from `getMic()` with `SET.mic` as deviceId, falls back to default) feeds a Web Audio chain `micChain()` = high-pass 85 Hz → **MIC BOOST** gain (`SET.mg`, default 220% on iOS / 160% elsewhere) → compressor → ×2 make-up → limiter → `MediaStreamDestination`; **that** stream (`voice.stream`) is what calls send, so switching mics (`switchMic` → `plugMic`) only swaps the source node, no renegotiation. The mic meter / noise detection still reads the raw mic (`voice.an`), so boosting doesn't make you louder to the Occupant. iPhone: `navigator.audioSession.type` = 'play-and-record' while the mic is on and right before `getMic` asks (`setAudioSession(true)`), 'auto' otherwise. **Never 'playback'**: in that mode iOS refuses the mic with NotAllowedError even when Safari's mic setting is Allow — v0.28.1–0.28.7 set it in `sfx.init()` and broke the iPhone mic (fixed v0.28.8). `wakeAudio()` resumes a suspended/interrupted AudioContext on any touch/click/visibility and re-acquires a mic track iOS ended (`micLost`). Calls: `opusTweak` sdpTransform (in-band FEC, 40 kbps, mono) on call + answer; `voiceWatchdog` (2 s) closes calls with no stream after 12 s or ICE failed/disconnected ~8 s, and re-dials are spaced 3 s (`voice.retry`); if a remote's inbound `totalAudioEnergy` rises while our analyser on that call is pure silence 3 times, the call switches to direct `<audio>` playback (`c.direct`, volume via `el.volume`, no 3D). Untested on a real iPhone (sandbox can't reach PeerJS).
- **Background audio off (v0.28.7, Ryan):** `audioOff()` on `visibilitychange` hidden / `pagehide` / `freeze` suspends `sfx.ctx` (all sound + voice), pauses call `<audio>` elements and releases the mic (stops `voice.raw`, sets `voice.lost`; the sent `voice.stream` is the chain's destination so calls stay up, just silent). `audioOn()` on visible / `pageshow` / `resume` resumes and re-opens the mic via `micLost()`. `wakeAudio()`/`micLost()` do nothing while away.
- **Mic permission help (v0.28.6, Ryan: it just said "mic blocked")**: `getUserMedia` is always called straight from a tap (needed for the iPhone prompt). On failure `micHelp(e)` opens `#micHelp` with a reason per error (NotAllowed = the phone remembers an earlier Don't Allow; NotFound; NotReadable = another app has the mic) and iPhone steps (Safari: aA → Website Settings → Microphone; home-screen app: Settings → Apps → Safari → Microphone → Ask, then reopen the app). Buttons: ASK AGAIN (calls `voiceEnable(true)` from that tap), RELOAD & ASK AGAIN (sets `lvl0_askmic`; after reload the first tap anywhere asks), NOT NOW. `getMic` falls back to `{audio:true}` on Overconstrained/TypeError.
- **Devices** (settings, v0.28.1): MICROPHONE select (`#sMic`, `SET.mic`), SPEAKER/HEADPHONES select (`#sSpk`, `SET.spk`, `AudioContext.setSinkId`, only where supported — Chrome/Edge desktop; disabled with a note on iPhone/Safari/Firefox), MIC BOOST slider + a live level meter. `fillDevices()` runs when settings open, after the mic is allowed and on `devicechange`.

## How to work on it

- **Edit `index.html` with exact-match replacements** (Python `rep(old,new)` asserting one match worked well). Then syntax-check the module: extract the `<script type="module">` body to a `.mjs` and run `node --check`.
- **Module TDZ trap**: top-level code runs top to bottom; calling something that touches `sfx` (declared late) from earlier top-level code crashes. Defer with `queueMicrotask` or call only from event handlers/frame.
- **Testing**: Playwright + system Chrome (`/usr/bin/google-chrome`, flags `--use-gl=swiftshader --enable-unsafe-swiftshader`), serve the repo with `python3 -m http.server 8765 --directory <repo>` **started in the same command** (background servers die between turns). `window.__hp` exposes internals (G, me, level, MON, sfx, voice, ability, contextAction, …) for tests. Two-player tests: two pages in one context with `#localnet`; add `--disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows` and `bring_to_front()` the page that must tick (the host runs the simulation). Headless runs at low FPS, so game time runs slow — poll for conditions instead of fixed waits. Fake mic: `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`.
- Can't test real PeerJS (cloud server unreachable from the sandbox) — voice/online needs Ryan to try it.
